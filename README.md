## 🌟 Điểm Nổi Bật

- **Thẩm mỹ có gu riêng (Wabi-Sabi & Highland Boutique):** Tông màu mộc mạc, bố cục thanh thoát phong cách tạp chí kiến trúc (Editorial), không bị công nghiệp hay sáo rỗng.
- **Dữ liệu & Vận hành thực tế:** 
  - Địa chỉ: Số 24/6 đường Khởi Nghĩa Bắc Sơn, Phường 10, TP. Đà Lạt, Tỉnh Lâm Đồng.
  - Hotline Quản lý: **0938 126 899** (Ms. Thúy An) | Kỹ thuật & Check-in: **0909 238 679** (Mr. Lâm).
- **Bộ sưu tập 4 gian phòng độc bản:**
  - *The Glass Sanctuary* (Phòng kính panorama 3 mặt, bồn tắm thảo mộc view thung lũng).
  - *The Pinewood Attic* (Gian áp mái thông mộc Chile, cửa sổ trời ngắm sao, lò sưởi ấm).
  - *The Garden Courtyard* (Căn hộ 2 phòng ngủ riêng biệt, bếp mộc và hiên hoa cẩm tú cầu).
  - *Lal Angle En-bloc* (Bao trọn khuôn viên biệt lập, hồ sục nước ấm ngoài trời 32°C, sân BBQ).
- **Hệ thống Reservation Engine thời gian thực:**
  - Tự động tính số đêm và tổng tiền phòng theo từng hạng phòng.
  - Tích hợp gửi thông báo Telegram tức thì về điện thoại quản lý homestay.
  - Bảng điều khiển quản lý đơn đặt phòng lưu trữ cục bộ an toàn.
- **Tối ưu di động (Mobile-First):** Tốc độ tải trang dưới 1.5 giây, tương thích hoàn hảo từ màn hình điện thoại đến máy tính.
- **Tiện ích trải nghiệm:** Nút bật âm hưởng gió đồi thông tự nhiên, sao chép nhanh số tài khoản chuyển cọc 1 chạm.

## 🛠️ Công Nghệ Sử Dụng

- **Frontend:** HTML5 ngữ nghĩa, Vanilla CSS (Design Tokens, Flexbox/Grid, Glassmorphism, Micro-interactions), JavaScript ES6+ thuần (Zero dependency, siêu nhẹ).
- **Thông Báo & Tích Hợp:** Telegram Bot API (`sendMessage`), Web Audio API (Synthesized Breeze Sound).
- **Deployment:** Tương thích 100% với Vercel, Netlify, GitHub Pages (chỉ cần kéo thả hoặc push code).

## 🚀 Hướng Dẫn Cài Đặt & Chạy Thử

### Cách 1: Mở trực tiếp
Nhấp đúp chuột vào tệp `index.html` để mở ngay trên trình duyệt bất kỳ.

### Cách 2: Chạy với Node.js / npx serve
```bash
# Cài đặt và khởi chạy máy chủ tĩnh
npm start
# Hoặc
npx serve -l 3000 .
```
Mở trình duyệt và truy cập: `http://localhost:3000`
